## Add a simple password gate (shared password, sessionStorage-based)

Add a lightweight password protection layer to the app so only people with the shared password can access the prototype. This is for demo access control, not production security.

### 1) Create a `/login` route

- Create `app/login/page.tsx`.
- Show a simple centered card with:
    - App name or logo (e.g., "DTO Diagnostic Baseline (v0)")
    - A password input field (type `password`)
    - A **"Enter"** button
    - If wrong password: show a red error message "Incorrect password"

### 2) Set the shared password

- Store the password as an environment variable: `DEMO_PASSWORD`
- Set it in Replit Secrets (e.g., `DEMO_PASSWORD=ozyntel2026`)
- Create an API route `app/api/auth/route.ts` that:
    - accepts POST `{ password: string }`
    - compares against `process.env.DEMO_PASSWORD`
    - returns `{ ok: true }` or `{ ok: false }`

### 3) Client-side auth state

- On successful login, store `sessionStorage.setItem("dto_auth", "true")`.
- On every page load (use a layout wrapper or middleware):
    - Check `sessionStorage.getItem("dto_auth")`.
    - If not set → redirect to `/login`.
    - If set → allow access.
- On browser tab close, `sessionStorage` clears automatically (so they need the password again next session).

### 4) Exclude `/login` from the auth check

- The `/login` page must be accessible without authentication (obviously).
- The `/api/auth` endpoint must be accessible without authentication.

### 5) Add a "Log out" option

- Add a small "Log out" link/button somewhere accessible (e.g., bottom of the sidebar or near the Reset button).
- On click: clear `sessionStorage.removeItem("dto_auth")` and redirect to `/login`.

### 6) Keep scope tight

- No real user accounts, no database, no JWT.
- Single shared password only.
- Do not change any existing functionality.

### 7) Verify

- Opening any page without entering the password redirects to `/login`.
- Entering the correct password grants access to the app.
- Closing the tab and reopening requires the password again.
- "Log out" clears access.
